# Asset workshop

Working files for the mod's art: editor projects (`.pxc`, `.ase`), UV maps and other sources that the finished
textures and models are made from.

This folder is kept in version control but is not part of the mod. The game only loads what is under
`JumpingSpiders/assets/`, and the release zip is built from that folder, so nothing here is shipped. Export
finished files (for example `silk_hammock.png`) into `JumpingSpiders/assets/jumpingspiders/textures/`.
